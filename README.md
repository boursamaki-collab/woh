# សន្សំប្រាក់សហគមន៍ — គេហទំព័រ GitHub Pages + Supabase

- អ្នកទាំងអស់ **មើលបានតែប៉ុណ្ណោះ**។
- **Admin** ចូលដោយអ៊ីមែល និងលេខសម្ងាត់ ទើបបន្ថែម កែ លុបទិន្នន័យបាន។
- ការការពារស្ថិតនៅក្នុងមូលដ្ឋានទិន្នន័យ (Row Level Security) មិនមែនត្រឹមលាក់ប៊ូតុងទេ។

## ជំហានដំឡើង (ប្រហែល ១៥ នាទី ឥតគិតថ្លៃ)

### ១. បង្កើតមូលដ្ឋានទិន្នន័យ Supabase
1. ចូល https://supabase.com ចុះឈ្មោះ រួចបង្កើត New project។
2. ចូល **SQL Editor** → បិទភ្ជាប់ឯកសារ `supabase/schema.sql` ទាំងមូល → Run។
3. បិទភ្ជាប់ `supabase/seed.sql` → Run (នាំចូលទិន្នន័យពី Excel)។

### ២. បង្កើតគណនី Admin
1. **Authentication → Users → Add user → Create new user** ។ បញ្ចូលអ៊ីមែល និងលេខសម្ងាត់ខ្លាំង ហើយ​ធីក Auto Confirm User។
2. **Authentication → Sign In / Providers → Email** ត្រូវបិទ **Allow new users to sign up** (កុំឱ្យអ្នកផ្សេងចុះឈ្មោះ)។
3. ក្នុង SQL Editor ដំណើរការ (ប្តូរអ៊ីមែលជារបស់អ្នក)៖
   `insert into admins(email) values ('your-admin@example.com');`

### ៣. ភ្ជាប់គេហទំព័រ
បើក `config.js` ហើយបំពេញពី **Project Settings → API**៖ `SUPABASE_URL` និង `SUPABASE_ANON_KEY` (កូនសោ anon/public)។
**កុំដាក់ service_role key ក្នុងគេហទំព័រជាដាច់ខាត។**

### ៤. ផុសលើ GitHub Pages
1. បង្កើត repository ថ្មីក្នុង GitHub រួចបង្ហោះឯកសារទាំងអស់ក្នុងថតនេះ។
2. **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** → Save។
3. រង់ចាំមួយភ្លែត គេហទំព័រនឹងនៅ `https://ឈ្មោះអ្នក.github.io/ឈ្មោះ-repo/`។

## ការប្រើប្រាស់
- ចុច **ចូលជា Admin** ខាងលើ។ ពេលចូលហើយ ប៊ូតុងកែប្រែលេចឡើងក្នុងផ្នែកនីមួយៗ។
- **កំណត់ត្រាសន្សំ → កត់ត្រាប្រចាំខែ**៖ បញ្ចូលហ៊ុនរបស់សមាជិកទាំងអស់ក្នុងមួយទំព័រ។
- បង្កើតកម្ចី ការប្រាក់ និងថ្ងៃត្រូវសងគណនាស្វ័យប្រវត្តិ។ ពេលសងដើមគ្រប់ ស្ថានភាពប្តូរជា «សងរួច»។
- **បិទបញ្ជីចុងឆ្នាំ** → កែតម្លៃកំណត់ (តម្លៃហ៊ុន ថ្លៃរដ្ឋបាល ការប្រាក់ អត្រាកាត់ទុក)។

## ម៉ូដសាកល្បង
បើ `config.js` នៅទទេ គេហទំព័រប្រើទិន្នន័យគំរូក្នុងអង្គចងចាំ (ចូល Admin ដោយអ្វីក៏បាន) ហើយមិនរក្សាទុកអ្វីទេ។ ត្រូវបំពេញ config.js មុនផុសសាធារណៈ។

## ឯកជនភាព
លេខទូរសព្ទសមាជិកមិនត្រូវបាននាំចូលទេ ព្រោះគេហទំព័រ និងឈ្មោះសមាជិកអាចមើលបានជាសាធារណៈ។
